# 🏋️ Avada Gym | Fitness Landing Page

A fully responsive, animation-rich gym landing page built with **pure HTML5 and modern CSS3** — no frameworks, no dependencies.

This project recreates a premium fitness-brand website: full-screen hero sections, service highlights, trainer profiles, testimonials, and a blog feed, all styled with native CSS nesting and a bold red-and-charcoal theme.

## ✨ Features

- 🦸 **Full-Screen Hero:** Bold header with background image, navigation, and dual call-to-action buttons.
- 💪 **Service Highlights:** Strength & Conditioning, Fitness & Cardio, Flexibility & Rest, and Health & Diet cards with icon accents.
- 📝 **Free Session Sign-Up:** Inline lead-capture form styled to match the dark theme.
- 🏟️ **High Performance Facilities:** Gallery grid showcasing gym equipment and classes.
- ⭐ **Testimonials Grid:** Real-world results section with member reviews.
- 💬 **Quote of the Day:** Full-width motivational quote block.
- 🧑‍🏫 **Trainers Showcase:** Profile cards with social links per trainer.
- 📰 **Blog / News Feed:** Card-based layout for the latest articles.
- 🦶 **Themed Footer:** Split layout with social links and signature typography.
- 🎨 **Custom Theming:** Centralized color palette via CSS `:root` variables.
- 🧩 **Modern CSS Nesting:** Scoped, framework-free nested selectors for maintainable styles.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Semantic markup and page structure |
| CSS3 (native nesting) | Layout, theming, and animations |
| Font Awesome | Icon set for social and UI icons |
| Fontello | Custom icon font for service cards |
| Google Fonts | Montserrat & Beau Rivage typefaces |
